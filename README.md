# Faceit: Block Strike — Telegram-бот

Стек: Python 3.11+, aiogram 3 (webhook-режим), Turso (облачный SQLite), хостинг Render.com Free.

## Обновление: список серверов, баннеры, настройки комнаты, фикс дубликатов

В этой версии добавлено:
- Раздел **"🖥 Сервера"** в главном меню — список открытых комнат с игроками, названием, регионом и ссылкой.
- Фото-баннеры при открытии разделов "Сервера", "Профиль", "Создание комнаты" (файлы в `assets/`).
- Мастер создания комнаты: выбор размера (2/4/6/8/10), названия и региона перед созданием.
- Исправлен баг: игрок, уже находящийся в активной комнате, больше не может создать или войти в другую, пока не закончит текущую.

**Важно при обновлении репозитория:** в этот раз изменения затронули много файлов сразу
(`database.py`, `states.py`, `keyboards.py`, `utils.py`, `handlers/room.py`, `handlers/menu.py`)
плюс появилась новая папка `assets/` с картинками. Проще и надёжнее не редактировать файлы по одному,
а удалить старое содержимое репозитория и загрузить актуальную папку `faceit_bot` целиком заново
(перетащить в "Upload files", убедившись, что все файлы и папка `assets` легли в корень репозитория,
без обёртки `faceit_bot` сверху — так же, как мы делали в самый первый раз).

После загрузки Render передеплоит сервис автоматически. Специально отключать бота вручную перед
обновлением не нужно — обычный передеплой сам ненадолго перезапускает процесс.

## Структура проекта

```
faceit_bot/
  main.py           — точка входа, aiohttp-сервер + webhook
  config.py          — все настройки (через переменные окружения)
  database.py         — вся работа с БД (Turso)
  states.py           — состояния FSM
  keyboards.py        — инлайн-клавиатуры
  utils.py            — расчёт уровня, случайное распределение команд
  background.py       — фоновая проверка дедлайнов (готовность / скрины)
  handlers/
    registration.py   — /start, верификация BS ID / nickname / TG user
    menu.py            — профиль
    room.py            — создание комнаты, готовность, распределение, приём скринов
    moderation.py       — админ-панель, начисление ELO/K-D/H-K
```

## Что нужно сделать вам (подробно)

### 1. Создать бота у @BotFather
1. Откройте Telegram, напишите **@BotFather**.
2. `/newbot` → укажите имя `Faceit: Block Strike` и юзернейм `BSFaceit_bot`.
3. BotFather пришлёт **токен** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`. Сохраните его — это `BOT_TOKEN`.

### 2. Узнать свой числовой Telegram ID
1. Напишите боту **@userinfobot** (или любому подобному) — он пришлёт ваш числовой ID.
2. Это значение — `ADMIN_ID`. Именно на него бот будет присылать заявки на верификацию и скриншоты на модерацию (то, что вы называли @xJetryy, но боту нужен именно числовой ID, а не юзернейм).

### 3. Завести бесплатную базу данных в Turso
1. Зайдите на **turso.tech** и зарегистрируйтесь (можно через GitHub, карта не нужна).
2. Установите Turso CLI по инструкции на сайте, либо создайте базу прямо в веб-панели (кнопка "Create Database").
3. После создания базы найдите:
   - **Database URL** — начинается с `libsql://...` — это `TURSO_DATABASE_URL`.
   - **Auth Token** — создаётся кнопкой "Create Token" — это `TURSO_AUTH_TOKEN`.
4. Схему таблиц создавать вручную не нужно — бот сам создаст их при первом запуске.

### 4. Выложить код на GitHub
1. Зарегистрируйтесь на **github.com**, если ещё нет аккаунта.
2. Создайте новый репозиторий (например, `faceit-block-strike-bot`), можно приватный.
3. Загрузите туда все файлы из папки `faceit_bot/` (через веб-интерфейс "Upload files" — самый простой способ, drag-and-drop всей папки).

### 5. Развернуть на Render.com
1. Зарегистрируйтесь на **render.com** (через GitHub — удобнее всего, карта не требуется).
2. New → **Web Service** → подключите репозиторий с ботом.
3. Настройки сборки:
   - **Runtime:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python main.py`
   - **Instance Type:** Free
4. В разделе **Environment** добавьте все переменные из `.env.example` со своими значениями:
   - `BOT_TOKEN`, `ADMIN_ID`, `BOT_USERNAME`, `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `WEBHOOK_SECRET` (придумайте любую случайную строку).
   - `WEBHOOK_HOST` — впишите **после** первого деплоя, когда Render выдаст вам адрес вида `https://faceit-block-strike-bot.onrender.com` (без слэша в конце).
5. Нажмите Deploy. После первого деплоя скопируйте выданный Render URL, впишите его в `WEBHOOK_HOST` и передеплойте (Render сделает это автоматически при сохранении переменной).

### 6. Настроить "будильник", чтобы бот не спал днём
1. Зарегистрируйтесь на **uptimerobot.com** (бесплатно, карта не нужна).
2. Add New Monitor → тип **HTTP(s)** → URL: `https://ваш-сервис.onrender.com/healthz` → интервал 5 минут.
3. В настройках монитора укажите расписание работы **06:00–00:00** (в UptimeRobot это делается через "Maintenance Windows" — наоборот, создайте окно обслуживания с 00:00 до 06:00, тогда в это время пинги не отправляются и бот спокойно засыпает).

### 7. Проверить, что всё работает
1. Напишите вашему боту `/start` в Telegram.
2. Пройдите тестовую верификацию (BS ID/nickname/TG user) — заявка должна прийти вам как админу с кнопками "Пропустить"/"Бан".
3. После одобрения — проверьте создание комнаты, кнопку "Я готов" (можно потестировать с несколькими своими тестовыми аккаунтами или друзьями).

### Что можно донастроить под себя
- Все числа (ELO-штраф, тайминги, карты, очки на победу) — в файле `config.py`, наверху с комментариями.
- Если Render всё же будет слишком часто "остывать" и мешать — можно позже перенести на любой другой хостинг с Docker/Python без изменений кода (main.py универсален).

Если что-то не запустится на этапе деплоя — пришлите мне текст ошибки из логов Render, разберём вместе.
